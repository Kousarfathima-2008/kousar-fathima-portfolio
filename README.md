A modern, attractive, and responsive personal portfolio website for **Kousar Fathima**, First-Year B.Tech Computer Science and Engineering student at **DR. RVR NRI College, Pothavarapadu** studying under **NIAT**.

## 🌐 Free Deployment Guide

### Deploying to GitHub Pages
1. Create a repository on [GitHub.com](https://github.com) named `portfolio`.
2. Push your files:
   ```bash
   git init
   git add .
   git commit -m "Kousar Fathima Portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings &rarr; Pages**, select the `main` branch, and click **Save**.

### Deploying to Vercel
1. Visit [Vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New... &rarr; Project**, select your repository, and click **Deploy**.
3. Your site will instantly be live on the web with a free HTTPS URL!
